# Code of Conduct

This project follows the spirit of the
[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

Be respectful, assume good faith, and keep discussions focused on making the
module safer and easier to audit. Harassment, personal attacks, and publishing
another person's private device data are not acceptable.

Maintainers may remove comments, close issues, or block participants who make
the project unsafe or hostile. To report a conduct issue, use the repository's
private contact channel rather than a public thread.
